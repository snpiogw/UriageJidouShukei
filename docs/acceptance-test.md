# 受入確認チェックリスト

## 事前条件

- Google Sheets APIが有効である
- サービスアカウントを対象スプレッドシートの編集者として共有している
- `売上データ` シートのA1:E1が `日付 / 担当者 / 商品名 / 数量 / 単価` である
- PostgreSQL、アプリケーションが起動している

## 正常系

- [ ] 管理者でログインできる
- [ ] 初期設定が「税込、10%、21:00、Asia/Tokyo」で表示される
- [ ] 税抜を選ぶと `数量 × 単価` が集計される
- [ ] 税込を選ぶと各行の `数量 × 単価 × (1 + 税率)` の1円未満が切り捨てられる
- [ ] 商品別、担当者別、月別、総売上が一致する
- [ ] 手動実行の受付後、画面操作を待たせず実行詳細へ遷移する
- [ ] 21:00の自動実行がQuartzの永続トリガーから起動する
- [ ] 再起動後も次回実行予定が復元される

## 入力エラー

- [ ] 必須項目の欠落行が集計対象外になり、行番号と修正方法が表示される
- [ ] 数量または単価が非整数の場合、集計対象外になる
- [ ] 日付形式が不正な場合、集計対象外になる
- [ ] 全行が不正な場合、既存の集計結果を上書きせずエラーログだけを更新する
- [ ] 10,000件を超える場合、処理を失敗として終了する

## 障害・競合

- [ ] Google Sheets APIに接続できない場合、実行履歴が失敗になる
- [ ] 同時に2回起動した場合、片方が `SKIPPED_CONCURRENT` になる
- [ ] チャンク障害後の再開で、完了済み行が二重加算されない
- [ ] `FAILED` の実行詳細から再開し、同じ実行IDで完了できる
- [ ] 設定画面を複数タブで更新した場合、古い画面からの更新が競合として通知される

## セキュリティ

- [ ] 未認証で管理画面へアクセスするとログイン画面へ遷移する
- [ ] POST操作にCSRFトークンが必要である
- [ ] サービスアカウントJSONと環境変数がGit管理対象外である
- [ ] 本番環境で開発用パスワードを使用していない
