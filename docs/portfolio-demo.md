# 2分デモ手順

## 0:00–0:20 課題と構成

Google Sheetsの売上入力をSpring Batchで検証し、商品・担当者・月別へ自動集計するシステムです。Profileごとに入力元、列名、税設定、時刻を管理し、PostgreSQLへ実行状態と監査履歴を保存します。

## 0:20–0:45 設定画面

管理画面でSpreadsheetへのリンク、稼働状態、次回予定、最終実行の件数と処理時間を示します。設定を無効化すると手動・Quartzの両方を停止できます。

## 0:45–1:20 正常系

「今すぐ集計」を実行し、受付済み→実行中→成功への遷移を見せます。Google Sheetsで商品・担当者・月別結果と、税込/税抜計算の結果を確認します。

## 1:20–1:45 異常系と再開

不正行は全体を止めずに除外し、行番号と修正方法を表示します。通信障害などのFAILEDは原因別コードを表示し、失敗地点から再開できます。再開後も最初の失敗は試行履歴に残ります。

## 1:45–2:00 品質

Spring SecurityのCSRF/BCrypt、Profile単位の排他、Flyway V1〜V6移行、Google APIタイムアウト、180日の保持期限、TestcontainersとGitHub Actionsを説明します。
